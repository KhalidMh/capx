## [0.1.0] - 2026-08-03

### Added

- Interactive `capx new` scaffolding for SAP CAP Node.js projects.
- JavaScript and TypeScript backend choices, with SQLite or Docker-backed PostgreSQL for development.
- SAP HANA Cloud or PostgreSQL on BTP deployment choices, MTA configuration, and optional XSUAA, IAS, Vite frontend, and approuter setup.
- Prerequisite checks, install guidance, rollback handling, dependency installation, and initial Git repository creation for generated projects.
- Generated service, database, test, formatting, and Docker configuration where selected.
